# 🎲 Tic-Tac-Toe Game

A classic **Tic-Tac-Toe** game built with **HTML, CSS, and JavaScript**.  
This project recreates the timeless two-player strategy game with a simple, interactive interface.

---

## 📖 Overview
The Tic-Tac-Toe game allows two players to:
- Take turns marking **X** and **O**
- Compete to align three marks in a row (horizontally, vertically, or diagonally)
- Enjoy a clean and responsive design

---

## 🛠️ Tech Stack
- **HTML5** – Game structure
- **CSS3** – Styling and layout
- **JavaScript (ES6+)** – Game logic and interactivity

---

## ✨ Features
- 🎮 Two-player mode
- 🧩 Win detection for rows, columns, and diagonals
- 🔄 Reset button to restart the game
- 📱 Responsive design for desktop and mobile
- ⚡ Lightweight and fast performance

##🎯 How to Play
Player 1 is X, Player 2 is O

Take turns clicking on empty squares

First player to align three marks wins

If all squares are filled without a winner, it’s a draw
